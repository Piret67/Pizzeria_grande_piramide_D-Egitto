## 📌 Presentazione del progetto

**Grande Piramide d'Egitto** è una piattaforma web dedicata alla valorizzazione e alla promozione della nostra pizzeria.

Il sito nasce per offrire ai clienti un'esperienza digitale intuitiva, moderna e accessibile, permettendo loro di conoscere il locale, esplorare il menù e scoprire i prodotti disponibili.

L'obiettivo è rafforzare la presenza online dell'attività attraverso un'interfaccia professionale, una navigazione semplice e una presentazione curata dei prodotti.

## 🎯 Obiettivi aziendali

- Rafforzare l'identità digitale della pizzeria.
- Migliorare la visibilità online del locale.
- Presentare il menù in modo professionale.
- Facilitare la consultazione dei prodotti.
- Offrire un'esperienza di navigazione intuitiva.
- Rendere il sito accessibile da dispositivi desktop, tablet e smartphone.

## 🏠 Struttura del sito

Il sito è organizzato attraverso una Home Page principale e una barra di navigazione che consente di raggiungere le diverse categorie.

### Navbar – Navigazione principale

| Sezione | Funzionalità |
| --- | --- |
| 🏠 Home | Presentazione della pizzeria e contenuti principali. |
| 🍕 Pizze | Consultazione del catalogo delle pizze. |
| 🥤 Bevande | Visualizzazione delle bevande disponibili. |
| 🍰 Dolci | Consultazione della selezione di dessert. |

### Home Page

La pagina principale rappresenta il punto di accesso al sito e comprende:

- Presentazione del brand.
- Immagini rappresentative della pizzeria.
- Messaggio di benvenuto.
- Accesso rapido alle categorie del menù.
- Elementi grafici coerenti con l'identità del locale.

### Menù digitale

Il menù è suddiviso in tre categorie:

**🍕 Pizze**

- Nome del prodotto.
- Descrizione e ingredienti.
- Prezzo.
- Immagine illustrativa.

**🥤 Bevande**

- Nome della bevanda.
- Descrizione.
- Prezzo.

**🍰 Dolci**

- Nome del dessert.
- Descrizione.
- Prezzo.
- Immagine illustrativa.

# 👨‍💻 GUIDA PER GLI SVILUPPATORI

Questa sezione contiene le informazioni necessarie per installare, comprendere e sviluppare il progetto.

## 1\. Requisiti

Prima di iniziare lo sviluppo è consigliato avere installato:

- Un editor di codice (consigliato Visual Studio Code).
- Un browser moderno (Chrome, Firefox, Edge).
- Git.
- Un account GitHub.

## 2\. Clonazione della repository

Per ottenere una copia locale del progetto, eseguire il comando:

bash

```bash
git clone URL_DELLA_REPOSITORY
```

Accedere successivamente alla cartella:

bash

```bash
cd NOME_DELLA_REPOSITORY
```

## 3\. Apertura del progetto

Aprire la cartella del progetto con Visual Studio Code:

bash

```bash
code .
```

In alternativa, aprire manualmente la cartella tramite l'editor.

Se il progetto utilizza HTML, CSS e JavaScript senza framework o dipendenze aggiuntive, è possibile avviare il sito aprendo `index.html` nel browser.

## 5\. Convenzioni di sviluppo

Per mantenere il codice ordinato e facilmente manutenibile, gli sviluppatori dovranno seguire alcune convenzioni:

- Utilizzare nomi di file e classi descrittivi.
- Mantenere separati HTML, CSS e JavaScript.
- Evitare duplicazioni di codice.
- Utilizzare immagini ottimizzate per il web.
- Scrivere codice leggibile e commentato quando necessario.
- Verificare la compatibilità con dispositivi mobili.
- Testare le modifiche prima di pubblicarle.

## 6\. Gestione delle modifiche con Git

Per aggiornare il progetto:

bash

```bash
git pull origin main
```

Per aggiungere nuove modifiche:

bash

```bash
git add .
```

Per registrare le modifiche:

bash

```bash
git commit -m "Descrizione delle modifiche"
```

Per pubblicare gli aggiornamenti:

bash

```bash
git push origin main
```

È consigliato lavorare su branch separati per nuove funzionalità:

bash

```bash
git checkout -b feature/nome-funzionalita
```

Al termine dello sviluppo, aprire una Pull Request per sottoporre le modifiche a revisione.

## 7\. Controlli prima del rilascio

Prima di pubblicare una nuova versione verificare:

- [ ]La navigazione tra Home, Pizze, Bevande e Dolci.
- [ ]La corretta visualizzazione delle immagini.
- [ ]Il funzionamento dei collegamenti.
- [ ]La compatibilità con smartphone e tablet.
- [ ]La corretta visualizzazione su diversi browser.
- [ ]L'assenza di errori nella console del browser.
